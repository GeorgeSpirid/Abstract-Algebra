# Abstract Algebra — Harvard Math E-222 / Artin's *Algebra*

Personal study repository following Benedict Gross's **Math E-222** lecture series (Harvard Extension School, Fall 2003) alongside Michael Artin's **Algebra** (2nd edition).

## Contents

| File | Description |
|---|---|
| `notes.pdf` | Lecture notes (Lec 1–36). |
| `exercises.pdf` | 100 solutions to some of the book's exercises with my ten favorite being: 2.6.2, 2.10.3, 3.2.15, 6.3.18, 6.4.3, 10.4.4, 11.2.5, 11.4.6, 11.7.5, 11.10.3. |
| `questions.pdf` | Used for quick review over the most important parts of the course material. |
| `Sylow-proofs.pdf` | The most interesting proofs of the course. So if you do not have time to go through all the material you can just look at this short pdf. |

## Topics covered

- **Groups**: subgroups, cosets, Lagrange's theorem, normal subgroups, quotient groups, isomorphism theorems, group actions, Sylow theorems, simple groups, symmetric/alternating groups, dihedral groups, motions of the plane
- **Linear algebra**: vector spaces, linear transformations, eigenvalues/eigenvectors, invariant subspaces, Cayley–Hamilton, orthogonal groups
- **Rings**: subrings, ideals, ring homomorphisms, quotient rings, polynomial rings, PIDs, UFDs, Euclidean domains
- **Number theory**: Gaussian integers, algebraic integers, quadratic fields, unique factorization, Dedekind domains, fractional ideals, ideal class groups
